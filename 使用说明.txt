# 算法档案 · AlgoArchive

这是面向 Windows 10 / 11 64 位电脑的本地竞赛题解与算法模板管理工具。界面为中文，左侧固定提供 Codeforces、AtCoder 常用视图，完整比赛和题目平台都可自由输入。用户数据默认保存在当前 Windows 用户目录，不进入程序目录。

## 三步启动

1. 将压缩包完整解压。不要直接在压缩包中双击运行。
2. 将解压得到的「算法档案」文件夹放到一个可写目录，例如 D:\Tools\算法档案，保持 runtime、web、启动.bat 等文件在同一目录结构中。
3. 双击 启动.bat（start.bat 是同一个启动入口的英文名称）。程序会启动本地服务，并优先使用 Google Chrome 打开页面；找不到 Chrome 时使用 Windows 默认浏览器。请在使用期间保留命令行窗口；关闭该窗口即停止服务。

内置官方 Python 3.13.9 的 Windows x64 嵌入式运行环境，不需要另装 Python，不需要执行 pip，不需要管理员权限，不需要联网下载依赖。首次打开时数据库会自动创建，初始题库为空。

浏览器未自动打开时，在地址栏输入启动窗口显示的地址。默认地址为 http://127.0.0.1:8765。端口占用时以窗口实际提示为准。

## 日常使用

- 首页概览：查看比赛、题目和各平台数量，以及最近修改记录。
- Codeforces / AtCoder：按平台集中查看比赛和题目。
- 完整比赛：创建比赛，平台可自由输入，也可填写洛谷、牛客等其他平台的标题和链接；进入比赛后添加同平台题目。
- 全部题目：统一查看所有题目，可搜索并按平台、比赛、代码语言筛选；自定义平台也会进入筛选选项。
- 算法模板：创建“树状数组”等算法，在同一个算法下关联相关题目，并保存多份代码和多条参考链接。
- 题目编辑：填写编号或名称、平台、题目链接、语言和代码。平台可自由输入，链接不限制域名或格式；比赛可不选，之后可随时关联已有比赛。
- 题目列表：点击题目名称打开原题链接；点击题目所在行的空白区域查看只读代码；操作列只保留“编辑”和“原题”。只读预览不会进入编辑状态。
- 代码编辑：支持基础语法高亮、Tab 缩进、回车自动缩进、复制，以及 Ctrl+S 保存（macOS 浏览器为 Cmd+S）。代码不会被执行或提交到平台。单道题目的代码上限为 2 MiB。
- 代码区使用 VS Code 风格的浅色语法配色；文本选择显示为蓝色，并严格高亮实际选中的字符范围。

C++ 保存为 .cpp，Python 为 .py，Java 为 .java，其他语言为 .txt。编辑语言会调整同一道题目的文件扩展名，不会保留旧语言副本。

## 统一题库与关联

比赛页和全部题目页使用同一条题目记录。无论从哪里添加、编辑、关联或取消关联，都不会创建第二份代码。比赛和题目链接都按原文保存，不判断是否为官方地址或有效 URL；同一平台下题目链接原文完全一致时，界面会提示打开已有记录。Codeforces、AtCoder 名称不区分大小写，其他平台名称原样保存。

同一题目最多关联一个已保存比赛；比赛与题目的平台必须一致。编辑比赛标题后，题目列表显示的比赛名称同步更新。多浏览器标签同时编辑时，过期版本不能直接覆盖新版本；请先复制未保存内容，再重新打开最新记录。

全部题目和算法详情都可以按住题目左侧的拖动手柄，用鼠标拖到目标位置来调整顺序。全部题目还提供“逆序排列”，会反转整套全局题目顺序。全部题目顺序与算法内顺序独立保存，不会修改代码或比赛关联；平台、比赛和算法详情等入口仍使用各自原有排序。

“全部题目”页的“导入”支持 JSON 文件，单次最多 200 道题目。每道题目支持 platform、number、name、url、language、code、contest、algorithm 字段；contest 和 algorithm 填写已保存的比赛标题或算法名称。重复题目会使整次导入停止，不会只写入其中一部分。

## 删除与保留

- 取消关联：保留题目和代码，只移除所属比赛。
- 删除比赛：可选择保留题目及代码，或一并删除该比赛下的题目及代码。
- 删除题目：需要明确确认，将删除对应题目记录和代码文件，不能在应用内撤销。

重要代码建议定期手动备份。默认数据目录是 %LOCALAPPDATA%\AlgoArchive\data。停止程序后，复制整个 data 文件夹即可完整备份；恢复时也应先停止程序，再替换整个 data 文件夹。请不要只复制数据库或单独替换某个代码文件。

## 文件说明

- 启动.bat / start.bat：启动入口。
- app.py：Python 标准库后端及 SQLite 数据管理。
- web/：离线网页、样式和编辑器；不加载在线字体或 CDN。
- runtime/：内置 Windows x64 Python 运行环境及其许可证。
- 用户数据：默认位于 %LOCALAPPDATA%\AlgoArchive\data，包含 archive.sqlite3 数据库和 codes/ 源代码文件。
- tests/：开发回归测试。
- 自检.bat：对临时测试目录运行回归测试，不使用或修改正式题库。
- TEST_REPORT.md：本交付版本的验证范围。
- THIRD_PARTY.txt：第三方运行环境来源和许可证说明。

代码文件采用题目或代码模板唯一 ID 命名，避免题名变化、重复名称或 Windows 文件名限制导致丢失。数据库只长期保存元数据和相对文件路径；保存时的临时恢复日志用于异常中断后的文件落盘，完成后会清除。

## 发布到 GitHub

项目目录不应包含 data 文件夹、archive.sqlite3、codes 文件夹或 runtime.lock。发布前请确认这些内容没有被加入提交；如果个人数据曾经进入 Git 历史，仅添加 .gitignore 不能删除历史记录，需要清理历史后重新发布。

## 常见问题

双击后提示找不到 runtime/python.exe。 说明压缩包没有完整解压，或运行环境目录被移动。请重新完整解压，保持文件夹结构。

修改代码后页面刷新没有保存。 编辑后需点击保存或按 Ctrl+S，看到保存成功提示才完成。离开有未保存内容的编辑页会提醒确认。

代码文件被外部移动、删除或写入权限不足。 先停止程序并备份整个目录，再恢复文件或目录权限。文件不可读时程序会提示错误，避免把缺失代码当作空代码覆盖。

链接打不开。核心管理功能可离线运行，但打开外部题目页面需要网络；备注型链接文本不会生成可打开地址。

换电脑。 退出程序后，把项目文件夹复制到另一台 Windows 10 / 11 x64 电脑，同时单独复制 %LOCALAPPDATA%\AlgoArchive\data。新电脑运行程序后，把数据放回对应用户的数据目录，或使用 --data-dir 指定位置。

其他系统。 随附运行环境仅适用于 Windows x64。macOS / Linux 开发者如已安装 Python 3.11 或更新版本，可在项目目录执行 python3 app.py。32 位 Windows 和 Windows 7 不属于本包支持范围。

本版聚焦本地管理，不包含在线题目信息抓取、编译运行、判题、代码版本历史、账号或云同步。
