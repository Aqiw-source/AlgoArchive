算法档案 · AlgoArchive 2.0.3
作者：Aqiw
GitHub：https://github.com/Aqiw-source/AlgoArchive

一、安装与启动

安装版：运行 AlgoArchive-2.0.3-Windows-x64-Setup.exe。安装完成后会自动创建
桌面快捷方式。仅当选择“仅为我安装”且当前账户没有配置时，向导才显示数据目录
页，并会把选择的目录写入配置。

为所有用户安装时会跳过数据目录页，每个 Windows 账户首次启动时使用自己的
默认目录；已有 %USERPROFILE%\AlgoArchive\config.json 时安装器不会覆盖配置。
需要更换目录时，请启动程序并在“设置 → 数据管理”迁移。

请下载 AlgoArchive-2.0.3-Windows-x64.zip，不要下载 GitHub 自动生成的
Source code (zip)。源码包不含 Python 运行环境，不能直接双击启动。

便携版：完整解压 ZIP 后双击 启动.bat。首次启动会自动创建桌面快捷方式；
也可以运行 创建桌面快捷方式.bat 手动刷新。不要把 启动.bat、runtime 和 web
分开移动。

程序只监听本机地址，默认打开 http://127.0.0.1:8765。端口占用时会选择后续
可用端口，并以启动窗口、设置页和实际打开的地址为准。

使用期间请保留启动窗口。关闭窗口、按 Ctrl+C，或在“设置 → 关于与诊断”
点击“退出算法档案”都可以停止服务。关闭普通浏览器标签页不会结束本地服务。

二、数据和配置

数据目录优先级：
1. 本次明确指定 --data-dir。
2. 当前用户配置文件保存的数据目录。
3. 默认 %USERPROFILE%\AlgoArchive\data。

用户配置默认位于：
%USERPROFILE%\AlgoArchive\config.json

2.0.3 起兼容旧安装器写出的 Windows ANSI/GB18030 配置；新安装器使用 UTF-8
无 BOM。中文用户名路径不会再导致配置解析失败。

程序目录与数据目录相互独立。默认数据目录包含：
- archive.sqlite3：比赛、题目、算法、个人资料和业务设置。
- codes：题目代码和算法模板代码。
- avatar：头像图片。
- runtime.lock：单实例锁和实际端口。

“设置 → 数据管理”显示当前生效目录，可以复制路径、打开文件夹或迁移到新的
完整数据目录。迁移前会检查目标状态并创建当前数据备份；迁移成功后需要重新
打开程序。

如果检测到两份可用旧数据，程序不会自动合并或覆盖，而会要求明确选择。
数据库版本过高、数据库损坏或关联代码缺失时，程序会拒绝写入并保留原数据。

三、浏览器

“设置 → 启动与浏览器”可以选择：
- Windows 默认浏览器。
- Microsoft Edge。
- Google Chrome。
- Mozilla Firefox。
- 自定义本机浏览器可执行文件路径。

窗口模式可选普通标签页或应用窗口。应用窗口仅对 Chrome / Edge 提供；其他
浏览器会说明并回退到普通标签页。程序不修改 Windows 全局默认浏览器。

“测试打开”会使用当前填写但尚未保存的设置。浏览器无法启动时会尝试系统
默认浏览器；仍失败时，请复制设置页显示的实际本地地址后手动打开。

四、题库使用

- 首页显示比赛、题目和算法数量。
- 完整比赛可自由填写平台，支持 Codeforces、AtCoder、洛谷、牛客等。
- 全部题目统一搜索和筛选，比赛与题目共享同一份记录和代码。
- 算法模板下可关联多道题目、保存多份代码和多个参考链接。
- 全部题目和算法详情支持鼠标拖动排序；全部题目支持一键逆序。
- 题目名称打开原题；点击题目行空白区域只读预览代码；编辑操作单独保留。
- JSON 导入单次最多 200 道题。重复题目会使整次导入停止，不会部分覆盖。

代码编辑支持 Ctrl+S 保存、Tab 缩进、回车自动缩进和复制代码。C++ 保存为
.cpp，Python 为 .py，Java 为 .java，其他语言为 .txt。单份代码上限 2 MiB。

五、备份与恢复

“设置 → 数据管理”可以创建完整 ZIP 备份、导入其他电脑的 ZIP、恢复列表中的
备份。备份包含 SQLite 数据库、全部代码、头像和业务设置。

恢复前会验证 ZIP 路径、清单、数据库版本和关联代码，并先备份当前数据。
恢复失败会保留或回滚当前数据。应用内最多保留最近 20 份备份。

配置文件中的浏览器绝对路径不写入备份，避免跨电脑恢复时强制使用旧机器路径。

六、日志与诊断

日志默认位于：
%USERPROFILE%\AlgoArchive\logs\algoarchive.log

日志轮转大小约 1 MiB，保留 3 个旧文件。日志不记录题目源码、数据库内容或
完整请求体。

“设置 → 关于与诊断”显示版本、实际服务地址、数据目录、配置文件、数据库版本
和日志路径，并可打开日志目录。

七、卸载和移动

安装版升级会复用既有安装位置并保留用户数据和配置。卸载默认不删除数据目录、
备份和配置。

便携版整体移动目录后，桌面快捷方式可能失效；请在新的完整目录中重新运行
创建桌面快捷方式.bat。数据目录不受程序目录移动影响。

八、开发与发布

运行测试：
python -X utf8 -m unittest discover -s tests -v
node --check web/app.js

构建便携 ZIP 和安装程序：
.\scripts\build-release.ps1 -Version 2.0.3

构建产物位于 dist，并生成 SHA-256 校验文件。发布包检查不会包含真实数据库、
用户代码、头像、runtime.lock、旧快捷方式、tests、缓存或备份。
