# AlgoArchive 在线演示设计

## 目标与范围

README 的“在线体验”链接打开 GitHub Pages 上的独立演示。复用现有 web 界面，使用公开核对的演示元数据，包含 Codeforces 下的 ICPC，以及蓝桥杯下的省赛、国赛。演示不进入本地安装程序的真实题库。

## 架构与数据流

- 新增 demo 数据 fixture 和仅在演示构建中加载的请求适配器；本地 web/index.html 不加载适配器。
- 构建脚本复制 web 静态资源到独立输出目录，修正项目子路径下的资源寻址，在 app.js 之前加载演示脚本。
- 适配器拦截同源 /api 请求，在当前页面内存中处理状态、详情、创建、编辑、锁定、删除和排序。刷新恢复初始 fixture；代码试跑草稿的浏览器存储也只限本站。
- 对不支持的 API 返回清楚错误，禁止回退到实际网络服务。编译运行、备份恢复、目录选择、系统启动和快捷方式仅本地版可用，不返回伪成功。
- 页面有持续可见的演示身份与刷新重置动作；所有系统操作提示安装本地版。

## 数据与安全

- fixture 只含公开题名、链接和明确标注的选编；不打包题面、用户数据或伪造的已通过题解。
- 树状数组编辑示例使用对应的完整代码及可核对样例，其余题目未填写解答。
- 蓝桥杯镜像链接明确在数据来源中注明；不冒充官网地址。元数据来源和核对日期随 fixture 保存。
- Pages 工件仅含静态 web 资源、演示脚本与 fixture；不含 Python、配置、数据库、真实代码或访问凭据。
- 演示站不连接 127.0.0.1，不读取本机题库，不加载第三方分析脚本。

## 部署与验证

- 独立 Pages workflow 构建、测试、上传并部署静态工件；不修改 Windows Release 工作流职责。
- 单元测试覆盖数据规模和分类、API 读写与锁定、刷新重置、禁止系统 API、子路径资源和工件隐私。
- Playwright 在 /AlgoArchive/ 子路径验证桌面和移动页面、资源、交互、刷新恢复和无控制台错误。
- 发布后核验公开在线入口、截图链接和页面资源；再完成 2.2.6 的 Windows 发布与本地升级，比较真实状态和配置哈希。

## 边界

静态演示不执行 C++，不提供后端文件系统或多人同步。GitHub Pages 部署需要仓库账户权限；权限不足时保留可部署工件并如实报告。Windows 安装包签名及干净虚拟机验收不由在线演示代替。
