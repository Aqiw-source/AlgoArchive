# 算法竞赛 · AlgoArchive

这是面向 Windows 10 / 11 64 位电脑的本地算法竞赛管理工具。界面为中文，支持 Codeforces、AtCoder，数据保存在当前程序目录中。

## 三步启动

1. 将压缩包完整解压。不要直接在压缩包中双击运行。
2. 将解压得到的「算法竞赛」文件夹放到 `C:\Users\Aqiw\Desktop\指令库`，使 `启动.bat` 位于 `C:\Users\Aqiw\Desktop\指令库\算法竞赛\启动.bat`。也可以放在其他可写目录。
3. 双击 `启动.bat`（`start.bat` 是同一个启动入口的英文名称）。程序会启动本地服务并打开默认浏览器。请在使用期间保留命令行窗口；关闭该窗口即停止服务。

内置官方 Python 3.13.9 的 Windows x64 嵌入式运行环境，不需要另装 Python，不需要执行 pip，不需要管理员权限，不需要联网下载依赖。首次打开时数据库会自动创建，初始题库为空。

浏览器未自动打开时，在地址栏输入启动窗口显示的地址。默认地址为 `http://127.0.0.1:8765`。端口占用时以窗口实际提示为准。

## 日常使用

- **首页概览**：查看比赛、题目和各平台数量，以及最近修改记录。
- **Codeforces / AtCoder**：按平台集中查看比赛和题目。
- **完整比赛**：创建比赛，填写平台、标题和链接；进入比赛后添加题目。
- **全部题目**：统一查看所有题目，可搜索并按平台、比赛、代码语言筛选。
- **题目编辑**：填写编号或名称、平台、题目链接、语言和代码。比赛可不选，之后可随时关联已有比赛。
- **代码编辑**：支持基础语法高亮、Tab 缩进、回车自动缩进、复制，以及 Ctrl+S 保存（macOS 浏览器为 Cmd+S）。代码不会被执行或提交到平台。单道题目的代码上限为 2 MiB。

C++ 保存为 `.cpp`，Python 为 `.py`，Java 为 `.java`，其他语言为 `.txt`。编辑语言会调整同一道题目的文件扩展名，不会保留旧语言副本。

## 统一题库与关联

比赛页和全部题目页使用同一条题目记录。无论从哪里添加、编辑、关联或取消关联，都不会创建第二份代码。平台和标准化题目链接用于检查重复：例如 Codeforces 的 contest 和 problemset 两种题目链接会被识别为同一道题。遇到已存在的题目时，界面会提示打开已有记录。

同一题目最多关联一个已保存比赛；比赛与题目的平台必须一致。编辑比赛标题后，题目列表显示的比赛名称同步更新。多浏览器标签同时编辑时，过期版本不能直接覆盖新版本；请先复制未保存内容，再重新打开最新记录。

## 删除与保留

- 取消关联：保留题目和代码，只移除所属比赛。
- 删除比赛：可选择保留题目及代码，或一并删除该比赛下的题目及代码。
- 删除题目：需要明确确认，将删除对应题目记录和代码文件，不能在应用内撤销。

重要代码建议定期手动备份。停止程序后，复制整个 `data` 文件夹即可完整备份；恢复时也应先停止程序，再替换整个 `data` 文件夹。请不要只复制数据库或单独替换某个代码文件。

## 文件说明

- `启动.bat` / `start.bat`：启动入口。
- `app.py`：Python 标准库后端及 SQLite 数据管理。
- `web/`：离线网页、样式和编辑器；不加载在线字体或 CDN。
- `runtime/`：内置 Windows x64 Python 运行环境及其许可证。
- `data/`：首次运行后自动创建，包含 `archive.sqlite3` 数据库和 `codes/` 源代码文件。
- `tests/`：开发回归测试。
- `自检.bat`：对临时测试目录运行回归测试，不使用或修改正式题库。
- `TEST_REPORT.md`：本交付版本的验证范围。
- `THIRD_PARTY.txt`：第三方运行环境来源和许可证说明。

代码文件采用题目唯一 ID 命名，避免题名变化、重复名称或 Windows 文件名限制导致丢失。数据库只长期保存元数据和相对文件路径；保存时的临时恢复日志用于异常中断后的文件落盘，完成后会清除。

## 常见问题

**双击后提示找不到 runtime/python.exe。** 说明压缩包没有完整解压，或运行环境目录被移动。请重新完整解压，保持文件夹结构。

**修改代码后页面刷新没有保存。** 编辑后需点击保存或按 Ctrl+S，看到保存成功提示才完成。离开有未保存内容的编辑页会提醒确认。

**代码文件被外部移动、删除或写入权限不足。** 先停止程序并备份整个目录，再恢复文件或目录权限。文件不可读时程序会提示错误，避免把缺失代码当作空代码覆盖。

**链接打不开。** 核心管理功能可离线运行，但打开 Codeforces / AtCoder 网站需要网络。

**换电脑。** 退出程序后，把整个项目文件夹复制到另一台 Windows 10 / 11 x64 电脑，再运行启动脚本。

**其他系统。** 随附运行环境仅适用于 Windows x64。macOS / Linux 开发者如已安装 Python 3.11 或更新版本，可在项目目录执行 `python3 app.py`。32 位 Windows 和 Windows 7 不属于本包支持范围。

本版聚焦本地管理，不包含在线题目信息抓取、编译运行、判题、代码版本历史、账号或云同步。
