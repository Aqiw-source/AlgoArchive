键盘快捷键与启动入口

键盘按键用于操作当前界面；Windows 启动快捷方式是桌面或开始菜单里的 .lnk 文件，用来启动本地程序。两者是不同功能。

本页目录编辑与保存浏览与预览选择与排序Windows 启动快捷方式

编辑与保存

表中使用 Windows 键名。在 Mac 浏览器体验在线演示时，保存、全选和复制可用 ⌘ 代替 Ctrl。题目名称链接用于打开原题；点击题目行的空白区域可只读预览代码。也可按 Tab 聚焦题目行本身，再按 Enter 或 Space 打开预览，按 Esc 返回列表。

保存当前编辑
Ctrl+S
在题目或模板编辑页保存当前修改；在「代码试跑」中保存浏览器本地草稿。
增加缩进
Tab
光标放在可编辑的代码区时插入四个空格。选中多行后，每行一起缩进。
减少缩进
Shift+Tab
在可编辑的代码区，将当前行或选中各行的行首缩进减少一级。
换行并续接缩进
Enter
新行沿用上一行的缩进。光标前的行内容以 { 或 : 收尾时，再缩进一级。

浏览与预览

打开代码预览
Enter / Space
在题目列表中用 Tab 聚焦题目行本身，再按 Enter 或 Space 打开只读代码预览。按 Esc 关闭预览，回到原来的列表和筛选位置。题目名称是独立的原题链接。
关闭题目代码预览
Esc
关闭当前代码预览，返回打开它的列表，保留原有搜索和筛选位置。
全选预览代码
Ctrl+A
在含有源码的预览窗口中，选中这一份代码。
复制选中代码
Ctrl+C
先选中预览代码再复制，也可以直接点「复制代码」。
打开比赛或算法分类
Enter / Space
焦点在比赛或算法卡片本身时，进入该卡片对应的详情页。
切换放大的插画
← / →
放大侧栏插画后，切换上一张或下一张。
关闭图片预览
Esc
关闭已放大的插画或头像。

选择与排序

浏览平台候选项
↑ / ↓
在平台输入框中展开列表，移动高亮选项。
确认高亮的平台
Enter
在平台列表中选中当前高亮项，并收起列表。
收起平台候选项
Esc / Tab
Esc 收起当前列表。Tab 收起列表并移到下一个可聚焦控件。
上移或下移一道题
Alt+↑ / Alt+↓
先聚焦题目行的排序手柄 ⠿。每次移动一位。平台题单启用了筛选时，先清除筛选。

Windows 启动快捷方式

本节适用于 Windows 本地版；在线演示不会创建或修改电脑上的 .lnk 文件。

从设置里创建或修复

  1. 打开正在运行的本地版，点左下角「设置」，选择「关于与诊断」。也可以点 前往创建快捷方式。若此页面通过 file:// 单独打开，先从完整程序目录双击 AlgoArchive.exe；也可在程序目录的 PowerShell 运行 .\AlgoArchive.exe --create-shortcut 创建桌面和开始菜单入口。
  2. 找到「快捷方式」，点「创建快捷方式」，等待界面显示完成或错误信息。程序会为当前 Windows 用户创建或刷新桌面和开始菜单入口。
  3. 回到桌面，或打开 Windows 开始菜单，找到「算法档案」。双击桌面图标或点开始菜单条目即可启动。

使用命令创建

在包含 AlgoArchive.exe 的完整程序目录打开 PowerShell，运行下面的命令。

.\AlgoArchive.exe --create-shortcut

同一目录也可运行 .\start.bat --create-shortcut。

安装、移动和固定

首次安装
安装器会创建开始菜单入口。「桌面快捷方式」默认未勾选，需要桌面入口时可在安装向导中勾选。
移动便携版后，旧图标打不开
完整移动程序目录，然后在新位置运行上述命令，或从新位置启动程序后通过设置重建。普通启动不会自动恢复已删除的快捷方式。
固定到开始或任务栏
程序只创建桌面和开始菜单入口，不会代替 Windows 固定磁贴或任务栏。是否能从右键菜单固定、可固定到哪里，取决于当前 Windows 版本；请在 Windows 开始菜单中自行操作。
