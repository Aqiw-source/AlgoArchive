浏览题目与预览代码

从首页找到代码，分清预览、编辑和原题入口。

本章导航 试一次：打开首页第一道题 按比赛查题 前往 Virtual Judge 查题或提交 赛事目录或全部题目，该从哪里找 练习：找回一场只有链接的比赛 搜索为空或打开了另一个页面

试一次：打开首页第一道题

  1. 回到首页，在「最近编辑」找到一道题。在线演示的第一题是 Tatami Renovation。
  2. 点击题目行的空白处查看代码；也可以先用 Tab 聚焦题目行，再按 Enter 或 Space。题名链接仍会打开原题。
  3. 按 Esc 或点「关闭」收起代码，会回到原列表并保留搜索、筛选和滚动位置，焦点回到题目行。点「复制代码」可复制整份源码。
  4. 要修改这道题，点「编辑」。保存后用「返回列表」或浏览器后退，回到打开编辑器前的筛选和滚动位置；要看比赛平台题面，点题名或「原题」。

按比赛查题

从左侧平台或比赛进入题目列表。题名前的 A、B 等编号按比赛理解；不同比赛的 A 题并不是同一道题。查看题名和所属比赛再编辑。

看到「暂无代码」？这表示题库暂时只收录了题目链接，可以照常打开原题。在线演示首页的 A–F 六题都有代码，其中 F 的用例是固定交互回放。

前往 Virtual Judge 查题或提交

首页的 Virtual Judge ↗ 会在新标签页打开第三方官网，原来的编辑页保持打开。请在该站自行登录、查找题目、选择语言并提交代码；评测结果也在该站查看。

AlgoArchive 与 Virtual Judge 无隶属、合作或授权关系。入口不会附带当前题目、源码、用例或账号凭据，也不会自动抓题、代交代码或把评测结果写回本地补题状态。

赛事目录或全部题目，该从哪里找

记得比赛名称时，先点侧栏「完整比赛」，打开对应场次，再按题号查找。只记得几个字时，进「全部题目」，在搜索框输入题名片段、题号或比赛名。先搜索再收窄平台，比在几个同名题之间逐个试点更快。

例如在演示库搜索 Tatami。先记下这一行的题名和比赛，再从横滨站的比赛列表找到它。两处显示的原题地址与代码应该一致。

练习：找回一场只有链接的比赛

  1. 在演示首页点「AcWing」，打开「第 163 场周赛」。比赛内有 A、B、C 三条记录。
  2. 找到 A「局部最小值」。点题名进入原题；原题地址以 /problem/content/6101/ 结尾，和列表里展示的题号不一样，打开链接时无需改写数字。
  3. 回到演示页，点击该题目行的空白区域。这次能看到保存的题目信息和「打开原题」入口。按 Esc 关闭后，仍在原来的比赛列表。

搜索为空或打开了另一个页面

确定存过，搜索结果却为空
先清空关键词，取消平台、比赛和语言筛选，再输入最确定的题名片段。在某个平台工作区里找不到时，切到「全部题目」重试。
我只想复制链接
点题目行的「复制链接」，然后在地址栏粘贴核对。平台标题旁的「复制链接」取的是官网首页。
打开了编辑页，想核对线上判题
用原题按钮前往对应平台，再到自己的提交记录查看。首页预览展示的是归档源码，本地状态和第三方提交记录分别保存。
