配置编译器与运行用例

用一个加法程序检查编译器、输入和期望输出。

配置一次编译器

在「设置 → 编译器」选择本机 MinGW 的 bin/g++.exe。下载的编译器压缩包要先完整解压；选择可执行文件后保存设置。

运行第一组测试

  1. 在题目编辑页填入下面的 C++ 程序，或在「代码试跑」临时尝试。
  2. 添加一组用例：输入 2 3，期望输出 5。运行当前用例，查看实际输出与比较结果。
  3. 再添加输入 -2 2、期望输出 0，运行全部。题目里要保留用例时点「保存用例」；已有 CPH 数据可导入 .prob 文件。
#include <iostream>
int main() {
    int a, b;
    std::cin >> a >> b;
    std::cout << a + b << '\n';
}
运行失败先看哪儿？编译失败先检查编译器路径和错误行；程序能运行但结果不符，先核对输入与期望输出。真实交互题还需要交互器，固定回放只能验证那次对话。
