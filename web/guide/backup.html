备份、恢复与启动问题

升级或换电脑前备份；区分运行服务与浏览器标签页。

本章导航 保留一个可以恢复的备份 关闭页面后，程序还在运行吗？ 换电脑时，哪些东西要带走 练习：做一次可对照的恢复演练 目录迁移、版本升级和浏览器窗口

保留一个可以恢复的备份

  1. 打开「设置 → 数据管理」，创建完整 ZIP 备份，记下文件位置与生成时间。
  2. 换电脑时，把 ZIP 复制到新电脑，在本地版导入备份。恢复会替换当前题库；如果目标电脑已有数据，先给它也做一份备份。
  3. 恢复后核对题目数，打开一题检查源码、用例、补题状态和错因笔记。

关闭页面后，程序还在运行吗？

浏览器标签页只是界面。通过桌面或开始菜单入口启动时，现有服务可能会复用。关闭普通标签页不会停止服务；状态窗口里会说明后台服务仍在运行。需要退出时，在「设置 → 关于与诊断」点「退出算法档案」，或关闭正在运行服务的启动窗口、按 Ctrl+C。

本地页面打不开或显示无法连接服务？不要直接双击 web\index.html；那只是网页文件，无法启动本地服务。请在完整安装目录中双击 AlgoArchive.exe，或在该目录打开 PowerShell 运行 .\start.bat，并保留启动窗口。启动窗口会显示实际地址；如端口不是默认值，请用显示的地址。离线手册可以直接打开，但题库和编译功能需先启动本地程序。

若需重建桌面和开始菜单入口，可前往 前往创建快捷方式。若此页面通过 file:// 单独打开，先从完整程序目录双击 AlgoArchive.exe；也可在程序目录的 PowerShell 运行 .\AlgoArchive.exe --create-shortcut 创建桌面和开始菜单入口。

升级后看不到原题库？先在设置里核对当前数据目录。程序目录和题库目录可能不同，不要把刚解压的安装目录当成数据目录恢复。

换电脑时，哪些东西要带走

题库的完整 ZIP 保存题目、比赛、算法模板、题目源码、用例、头像及业务设置。用浏览器保存的「代码试跑」草稿有单独的存储位置，需要保留时，先把重要代码归档为题目或自行复制保存。

编译器属于 Windows 程序环境。换电脑后重新确认 MinGW 的解压目录和实际 g++.exe 路径。指定浏览器的旧电脑绝对路径不会随题库备份恢复，也需要按新机器环境核对。

练习：做一次可对照的恢复演练

  1. 在旧电脑记下题目和比赛总数，挑一道包含代码、错因笔记和多组用例的题，再记下一份常用模板。这样恢复后有明确对象可对照。
  2. 创建完整 ZIP，把它复制到预定保存位置。应用内最多保留最近 20 份备份，重要的长期副本可另存。
  3. 在新电脑先打开本地版，确认是准备接收数据的题库。目标题库已有内容时，先为它制作自己的 ZIP，再选择旧电脑的备份进行恢复。
  4. 恢复后逐项核对题目数、比赛归属、示例题的代码与用例、模板和头像。最后运行一组已保存题目的简单用例，检查新电脑的编译配置。

目录迁移、版本升级和浏览器窗口

只想把题库从一个磁盘移到另一个磁盘
在「设置 → 数据管理」使用迁移，选择目标目录，按提示重新启动，再对照实际数据目录和题目数。
升级后界面正常但题库看着是空的
先查看设置里的实际数据目录，对照先前记录。找到原题库或已知备份后再决定迁移或恢复。
恢复后想退回刚才的内容
在备份列表里按时间确认恢复前的副本。恢复每一次都会替换当前题库，如果刚又增加了新题，先保存一份新的完整备份。
